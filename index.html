↗ NaviFree

The free-first app now runs on Next.js and NestJS.

From this project folder, with Node.js 22 or newer installed:

npm ci
npm run dev

Then open NaviFree at localhost:3000.

Local demo mode needs no API key, database, or cloud subscription. Mapbox and public prototype APIs are optional and disabled by default.

See README.md for setup, service limits, and checks. The original single-file prototype remains in Git history.
